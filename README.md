# Armada Solo Cards - v1 PDF Release

An unofficial fan-made solo-play aid for Mantic Games' *Armada*.  It is based on
the previusoly released solo rules but (hopefully) dramatically improved upon and 
modernised.

This release contains print-ready PDFs with cut lines:

- A4 normal-colour cards;
- A4 printer-friendly cards;
- US Letter normal-colour cards;
- US Letter printer-friendly cards;
- Armada Solo card-play guide.

## Choose the correct folder

```text
cards/
  a4/
    normal/             poker and tarot
    printer-friendly/   poker and tarot
  letter/
    normal/             poker and tarot
    printer-friendly/   poker and tarot
guides/
```

Do not print an A4 PDF on Letter paper or a Letter PDF on A4 paper.

## Printing

1. Print at **Actual Size / 100%**.
2. Disable Fit, Shrink, Scale to Fit, headers, footers and extra crop marks.
3. Use portrait orientation.
4. For automatic duplex, select **Flip on long edge**.
5. The card backs are already mirrored for duplex printing; do not mirror them again.
6. Print the first front/back sheet as a test before printing a complete set.

Expected finished dimensions:

- Poker: 63.5 x 88.9 mm (2.5 x 3.5 in).
- Tarot: 70 x 120 mm (approximately 2.75 x 4.75 in).

## Manual duplex

1. Print odd pages only; these are card fronts.
2. Reinsert the sheets using the orientation established by your test sheet.
3. Print even pages only; these are the matching backs.
4. Never mix front and back pages from different PDFs.

## Cutting

- Cut between matching trim marks using a ruler and knife or guillotine.
- Keep the sheet intact for as long as possible so later trim marks remain available.

## Release contents

- 16 poker-card PDFs: four card groups in four paper/treatment combinations.
- 8 tarot-card PDFs: scenario and map groups in four combinations.
- 1 instruction/guide PDF.

The three generic AI Fleet cards remain included.
